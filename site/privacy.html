Data & Privacy

数据路径，应当清楚地写出来。

本说明适用于桌面客户端 1.0.1+ 与 Chrome 扩展 1.0.0+。润笔不运营用于转发或存储用户文本的中间服务器；选中文本只会发往你在设置中配置的模型服务端点。

最后更新：2026-08-29。模型服务商自身的数据处理规则、留存政策与计费规则由该服务商决定，请在配置前自行确认。

1. 选中文本与剪贴板内容

选中的文本在本地内存中处理后，仅发送到你自行填写的模型服务端点，例如兼容的公共服务或私有网关。润笔厂商不提供、经过或存储该请求的中转服务。

本地敏感信息拦截

桌面端会拦截疑似密码、密钥、UUID、手机号、身份证号与银行卡号等整段敏感文本，不弹出、不发送。

密码输入框

浏览器扩展不会读取 type=password 输入框中的内容。

2. 屏幕截图

仅在你主动开启“智能回复视觉感知”并在聊天场景触发时，前台窗口截图会作为视觉输入发送到你配置的模型端点。该功能默认关闭，首次触发会明确询问；关闭后不发生截图。

截图仅存在于内存中用于当次请求，不落盘，也不会上传至润笔厂商。

3. 保存在本机的数据

数据位置说明
API Key桌面端配置目录使用 Windows DPAPI 加密，绑定当前用户。
润色历史桌面端配置目录默认近 100 条，可在设置中清除。
运行日志桌面端配置目录仅元数据，可在设置中清除。
扩展配置chrome.storage.local保存在浏览器配置目录中。

如需在卸载后完整清除桌面端本地数据，可手动删除 %APPDATA%\com.runbi.desktop。

4. 遥测与错误上报

桌面端默认不进行网络上报。只有当你主动开启错误上报并配置 DSN 时，才会上报错误堆栈与崩溃信息；上报内容会剥离请求体，不包含你选中或润色的文本。

官网已启用 Google Analytics 访问统计，用于记录页面访问、下载按钮、视频进度和 FAQ 互动等事件，不读取或发送你在润笔中处理的文本、API Key 或截图；统计平台可能依其政策接收设备与来源信息。

5. 自动更新

桌面端会向公开分发仓库检查并下载更新包。发布包的签名校验通过后才会安装；此过程不携带你的选中文本或模型 Key。

还有隐私问题？

安全、数据或隐私问题请通过公开问题反馈渠道提交。重大政策变更会在 Release 说明中标注。
