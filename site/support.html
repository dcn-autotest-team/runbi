Support

下载前说清楚，使用时少绕路。

这里汇总当前公开发布版本、安装方式、支持范围和已知限制。具体构建内容始终以 GitHub Release 的说明与安装包为准。

当前公开发布版本：v1.0.3。桌面端面向 Windows 10/11 64 位；安装包为 NSIS `.exe`，支持应用内签名校验更新。
安装更新支持范围已知限制获取帮助

1. 安装

Windows 桌面端

在公开 Release 中下载最新版安装包，运行 `.exe` 后按安装向导完成安装。首次使用时，根据你的模型服务商配置端点与 API Key。

前往下载 Release →

浏览器扩展

浏览器扩展主要用于网页编辑器和可编辑文本区域。安装方式、权限与当前构建产物以对应发布说明为准。

查看发布说明 →

2. 更新与校验

从 1.0.1 起，桌面端可以通过应用内更新通道获取后续版本。更新包会进行签名校验；若你希望手动更新，也可以直接从 Release 下载最新版覆盖安装。

如遇更新失败，请先查看应用内提示，再在反馈中附上版本号、错误提示与复现步骤；请勿提交 API Key、敏感文本或完整日志。

3. 当前支持范围

能力说明
选中后唤起面向可编辑文本和允许复制的内容；实际体验依目标应用行为而定。
润色与审阅结果以候选文本展示，支持在采用前审阅差异、复制或替换。
模型服务可配置当前版本支持的兼容端点与自带 Key；费用与服务规则由你的模型服务商管理。
平台公开桌面端为 Windows 10/11 64 位；浏览器能力以当前扩展发布说明为准。

4. 已知限制

受保护或只读内容

受保护 PDF、只读控件、密码输入框和部分企业防护环境可能限制取词、复制或替换。

部分复杂应用

部分 Electron 应用或特殊富文本控件的行为可能与网页编辑器不同。遇到问题时请使用手动粘贴入口并提交复现信息。

需要帮助？

提交时请提供：操作系统版本、润笔版本、目标应用名称、可公开的复现步骤和错误提示。不要提交 API Key、身份证号、客户消息或其他敏感内容。
