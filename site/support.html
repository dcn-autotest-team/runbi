1. 安装

Windows 桌面端

在公开 Release 中下载最新版安装包，运行 `.exe` 后按安装向导完成安装。首次使用时，根据你的模型服务商配置端点与 API Key。

前往下载 Release →

浏览器扩展

浏览器扩展主要用于网页编辑器和可编辑文本区域。安装方式、权限与当前构建产物以对应发布说明为准。

查看发布说明 →

2. 更新与校验

桌面端启动时会检查新版本；也可以在“人设与高级”中手动检查。发现更新后，应用会显示版本提醒，下载并通过签名校验后才安装。你也可以从 Release 下载最新版覆盖安装。

如遇更新失败，请先查看应用内提示，再在反馈中附上版本号、错误提示与复现步骤；请勿提交 API Key、敏感文本或完整日志。

3. 当前支持范围

能力说明
划词与快捷唤醒选中文字后显示胶囊，可进入润色、回复或翻译；也支持可配置的全局快捷键。划词触发与复制触发可分别开关。
润色与审阅支持通用、学术、商务、文采、精简与 AI 自动风格；可查看终稿或修改差异，复制、贴回并撤回上次贴回。
翻译支持英文、简体中文、繁体中文、日文和韩文五种目标语言。
智能回复可根据选中文字或可见聊天截图生成回复；支持人机协同预填，以及全自动发送 Beta。
个性化与内容库支持人设、行业模板、快捷指令、个人词库、文风样本、1480 条话术模板、277 位专家及 2–4 位专家并行对比。
历史与参考资料支持生成历史、草稿恢复、剪贴板参考，以及拖入 100KB 内可读取文本文件作为生成参考。
模型服务提供 DeepSeek、智谱 GLM-4、OpenAI 预设，支持自定义兼容端点，并可自动探测 Ollama 与 LM Studio。
平台公开桌面端为 Windows 10/11 64 位；浏览器能力以当前扩展发布说明为准。

4. 已知限制

受保护或只读内容

受保护 PDF、只读控件、密码输入框和部分企业防护环境可能限制取词、复制或贴回。

截图与自动应答

聊天截图理解需要支持视觉输入的模型；全自动无人值守应答仍为 Beta，重要沟通建议使用人机协同模式确认后发送。

部分复杂应用

部分 Electron 应用或特殊富文本控件的行为可能与普通编辑器不同。贴回失败时，结果会保留在剪贴板供你手动粘贴。

需要帮助？

提交时请提供：操作系统版本、润笔版本、目标应用名称、可公开的复现步骤和错误提示。不要提交 API Key、身份证号、客户消息或其他敏感内容。
