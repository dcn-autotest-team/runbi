## 2. 为什么做“润笔”？（核心痛点与洞察）

### 2.1 传统工作流的割裂（摩擦力高）
在日常办公、学术阅读、英文邮件撰写、社交媒体发文时，用户为了修改一段文字，往往需要：
1. `Ctrl + C` 复制文本；
2. 切标签页打开 ChatGPT / Claude / DeepSeek 网页；
3. 手打提示词：*“帮我把这段话润色得更学术一点/更地道一点，不要废话直接给结果”*；
4. 等待大模型输出一段冗长的客套话，再手动复制回原网页并粘贴替换。
**这一流程耗时 20~40 秒，严重打断心流。**

### 2.2 市面同类工具的不足
- **过于庞大臃肿**：很多 AI 插件试图做“全能工具箱”（聊天、翻译、摘要、搜索一锅端），导致弹窗杂乱、快捷键冲突、加载缓慢。
- **缺乏“差异对比（Diff）”**：改写后的文本无法一眼看出修改了哪些字词、修饰了哪些语法。
- **无法直接替换原输入框**：改好后仍需复制，不能“一键就地替换（In-place Replace）”。
- **数据隐私与 API 绑定**：强制用户购买昂贵的会员套餐，不支持自主配置 DeepSeek、OpenAI、Ollama 等低成本或本地模型。

## 3. “润笔”的核心价值主张 (Value Proposition)

1. **如影随形，轻如鸿毛**：  
   划选网页中任意文本，仅在光标附近出现轻巧的“润笔徽标”。点击即润，不挡视线，失焦即隐。
2. **专精润色，极致效率**：  
   摒弃繁琐聊天界面，直切“修辞润色、学术规范、职场公文、精炼降重、地道地气、扩写丰富”等开箱即用的预设卡片。
3. **字句对比，心明眼亮（Diff View）**：  
   独创文本差异比对高亮，红绿划线直观展现“删减何处、润色何词”。
4. **一键就地替换（In-Place Replace）**：  
   在 Gmail、飞书、Twitter、Notion 等编辑框中，润色完毕后点击“替换”，直接替代被选中的原始文本。
5. **BYOK (Bring Your Own Key) 隐私优先**：  
   用户可自由接入 DeepSeek-V3、GPT-4o、Claude 3.5、通义千问或本地 Ollama 模型，密钥仅保存在本地浏览器沙盒，绝不上云。

## 4. 目标用户画像 (Target Personas)

| 用户类别 | 典型场景 | 核心诉求 |
| :--- | :--- | :--- |
| **高校科研与硕博生** | 撰写英文论文、修改摘要、阅读文献注释 | 要求用词严谨、符合 IEEE/Nature 学术范式、消除中式英语 |
| **外企 / 出海职场人** | 撰写 Slack 消息、回复跨境客户邮件、周报整理 | 要求语气得体（Polite / Professional）、表达清晰通顺 |
| **内容创作者 / 自媒体** | 撰写知乎回答、微信推文、小红书文案 | 要求金句提炼、提升文采、修辞增强、扩写或精简 |
| **程序员 / 极客** | 编写 Git Commit、写 GitHub PR 描述、优化英文文档 | 追求极简、不占内存、支持自定义 API 和快捷键 |

## 5. 用户典型旅程 (User Journey)

```text
[网页浏览/输入框编辑]
      │
      ▼
[鼠标划选需要修改的文本]
      │
      ▼
[光标右上方优雅浮现“润笔”微标 / 或触发全局快捷键 Alt+W]
      │
      ▼
[弹出磨砂毛玻璃悬浮窗，流式输出默认润色结果]
      │
   ┌──┴────────────────────────┐
   ▼                           ▼
[切换不同润色风格标签]     [开启 Diff 差异高亮视图]
(学术 / 商务 / 文采 / 精炼)   (红删绿增，一目了然)
   │                           │
   └──────────┬────────────────┘
              ▼
    [一键复制 或 一键替换编辑框内容]
              │
              ▼
   [按 ESC 或点击空白处，浮窗瞬隐]
```

## 6. 演进路线规划 (Roadmap)

- **V1.0 (MVP 阶段)**：
  - 核心划词浮标与悬浮窗交互（Shadow DOM 隔离）。
  - 支持 OpenAI / DeepSeek API 流式输出。
  - 内置 6 大常用润色 Prompt 预设。
  - 支持一键复制与基础 Diff 比对。
- **V1.1 (增强交互)**：
  - 支持对 `<input>`、`<textarea>`、`contenteditable` 编辑框的一键就地替换。
  - 支持全局快捷键呼出。
  - 针对特定网站的开启/禁用白名单机制。
- **V2.0 (全生态扩展)**：
  - 引入本地 WebGPU / Ollama 离线运行能力。
  - 拓展至桌面全局端（借助 Tauri 开发系统级划词客户端）。
