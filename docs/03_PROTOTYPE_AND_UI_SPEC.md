
## 2. 交互状态转移与动画规范

```text
[ 用户划选文本 (mouseup) ]
           │
           ▼
[ 150ms 防抖检查 (长度 > 2) ] ── (未达标/点击空白) ──> [ 忽略 / 销毁面板 ]
           │
           ▼
[ 浮现 Trigger 徽标 (FadeIn + Scale 0.8 -> 1.0, 150ms 缓动) ]
           │
           ▼ (用户点击徽标 或 按 Alt+W)
[ 展开面板 (Spring 弹性展开，Height 自动伸展) ]
           │
           ▼
[ 发送 SSE 流式请求 -> 显示流式输出打字效果 -> 渲染完毕呈现操作按钮 ]
           │
           ├──> 点击 [复制] ──> 按钮变为 "✓ 已复制" (1.5s 后复原)
           ├──> 点击 [替换] ──> 宿主输入框替换内容，浮窗收起，页面闪烁绿色微光反馈
           ├──> 切换 Tab (如切到 "学术") ──> 中止当前请求，带新 Prompt 重新发起流式生成
           └──> 点击外部或按 ESC ──> 面板平滑淡出 (FadeOut 100ms)
```

## 3. 视觉规范与 Design Tokens

### 3.1 配色系统 (Color Palette)

| 语义角色 | 色值 (Light 浅色模式) | 色值 (Dark 深色模式) | 视觉说明 |
| :--- | :--- | :--- | :--- |
| **品牌主色 (Jade)** | `#00BFA5` | `#00E5A3` | 翡翠青，象征文字润泽生机 |
| **强调金色 (Gold)** | `#B38E46` | `#E0C075` | 香槟金，笔尖质感高光 |
| **背景色 (Surface)** | `#FFFFFF` (85%透明度毛玻璃) | `#121E1E` (90%透明度毛玻璃) | `backdrop-filter: blur(16px)` |
| **主文本 (Text-Main)**| `#1E293B` (Slate-800) | `#F8FAFC` (Slate-50) | 正文高对比度 |
| **次文本 (Text-Muted)**| `#64748B` (Slate-500) | `#94A3B8` (Slate-400) | 辅助提示与字数统计 |
| **边框分割 (Border)** | `rgba(0, 0, 0, 0.08)` | `rgba(255, 255, 255, 0.12)`| 极细发丝分割线 |
| **Diff-删除 (Del)** | 背景 `#FEE2E2` / 文字 `#DC2626` | 背景 `rgba(239, 68, 68, 0.2)` / 文字 `#F87171` | 红色横线删除 |
| **Diff-新增 (Ins)** | 背景 `#DCFCE7` / 文字 `#16A34A` | 背景 `rgba(16, 185, 129, 0.2)` / 文字 `#34D399` | 绿色高亮新增 |

### 3.2 圆角与投影 (Radius & Shadow)
- **面板卡片圆角**：`rounded-2xl` (`16px`)
- **按钮与输入框**：`rounded-lg` (`8px`)
- **微标外形**：`rounded-full` (`9999px` 胶囊形)
- **浮动阴影 (Elevation)**：  
  `box-shadow: 0 20px 25px -5px rgba(0, 0, 0, 0.1), 0 8px 10px -6px rgba(0, 0, 0, 0.1), 0 0 0 1px rgba(0, 0, 0, 0.05);`

## 4. Shadow DOM 样式隔离落地范式（代码架构参考）

为防止外部网页样式污染，Content Script 必须按如下范式挂载：

```typescript
// content/index.ts
export function mountRunbi() {
  const HOST_ID = 'runbi-extension-root';
  if (document.getElementById(HOST_ID)) return;

  const hostEl = document.createElement('div');
  hostEl.id = HOST_ID;
  hostEl.style.position = 'absolute';
  hostEl.style.top = '0';
  hostEl.style.left = '0';
  hostEl.style.zIndex = '2147483647'; // 最高层级，保证浮在任何网页之上
  document.body.appendChild(hostEl);

  // 创建 open 模式的 Shadow Root
  const shadowRoot = hostEl.attachShadow({ mode: 'open' });

  // 注入编译后的 Tailwind CSS 样式表字符串
  const styleEl = document.createElement('style');
  styleEl.textContent = __INJECTED_CSS_CONTENT__;
  shadowRoot.appendChild(styleEl);

  // 挂载 React / Vue 容器节点
  const appContainer = document.createElement('div');
  appContainer.id = 'runbi-app-container';
  shadowRoot.appendChild(appContainer);

  // 执行框架挂载，例如 ReactDOM.createRoot(appContainer).render(<App />);
}
```
