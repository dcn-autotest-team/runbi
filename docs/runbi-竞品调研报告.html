01 · 核心结论

没有人把「划词即润色」这条闭环做全 —— runbi 的空位是「中文 × 主动划词触发 × 原地替换 × Windows 桌面端」四者组合。
中文原生润色 + 轻交互，海外四款全都不做中文、且没有 Windows 原生客户端；中文竞品则形态不对，做润色的都是编辑器、做划词的白只翻译。

一句话定位：「在中文世界的任何角落，选中即润色，原地替换，隐私不上云。」

03 · 「划词即润色」闭环差异

runbi 的核心是「选中 → 浮窗 → 一键润色 → 原地替换」的轻交互闭环。横评后发现：四类竞品各卡在不同位置，没一个做全。

中文竞品

沉浸式翻译 / 沙拉查词

交互是划词浮窗，但只做翻译 / 查词，不做润色改写。

中文竞品

秘塔写作猫

做润色改写，但是编辑器形态，要打开网页，不能在任意页面原地划词替换。

海外竞品

DeepL Write

重写能力强，但整篇粘贴进工作台，非划词触发、不侵入第三方应用。

海外竞品 · 最接近

Grammarly

就地弹卡、原地替换、有桌面端；但是被动批改而非「选中哪段改哪段」，且基本不支持中文。

海外竞品 · 交互重合

QuillBot

扩展支持「选中 → 浮窗 → 原地替换 (In-Page Editing)」——交互模型与 runbi 高度重合，但不含中文、无 Windows 桌面端。

海外竞品

Wordtune

同样「选中 → 浮窗 → 原地替换」，但偏「多选一建议」而非一键；仅英文、无 Windows 桌面端。

04 · 两大直接威胁与对应打法

威胁 1 · 国内

大厂免费侧边栏助手（豆包 / Kimi / 通义）

  • 为何威胁最大：免费 + 大厂模型 + 品牌信任，划词问答 / 润色顺带覆盖。
  • 活路：不做「通用助手」，做「极轻专用」。通用助手交互重、要打开侧栏；runbi 主打划词即出、一秒换风格、原地替换，用完即走。
威胁 2 · 海外

Grammarly × QuillBot × Wordtune

  • 为何要避开：形态最接近（Grammarly/QuillBot 都有划词就地替换），用户规模碾压（Grammarly 4000万 / QuillBot 3500万）。
  • 活路：三者都不支持中文原生润色，且无 Windows 原生客户端——runbi 切入中文场景，避开其主场。

已走通的独立工具变现路径

沙拉查词、沉浸式翻译都验证了「免费铺量 + 开源 + 打赏 / 订阅」的独立开发者路径。商业模型可参考 QuillBot 慷慨免费拉规模 + Wordtune $7–20/月分级订阅变现（Basic 免费 / Advanced $6.99 / Unlimited $9.99 以上）。

05 · 海外四款统一结论

  • 语言是最大机会：QuillBot（6 语不含中文）、Wordtune（仅英文）、Grammarly（基本英文）都不做中文润色——「中文划词即润色」是结构性空白。唯一含中文写作的 DeepL Write 是整篇工作台形态，不做划词。
  • Windows 桌面端是差异化：QuillBot、Wordtune 都只有网页 + 扩展，无 Windows 原生客户端；Grammarly/DeepL 有桌面端但不支持中文划词润色闭环——runbi 的 Tauri 桌面端是壁垒。
  • 一键润色优于多选一：runbi 的一键润色比 Wordtune 的「多选一建议」交互更短，是可用性卖点。

06 · 差异化定位建议

在中文世界的任何角落，
选中即润色，原地替换，隐私不上云。

⚡ 轻

划词即出浮窗，一秒换风格（正式 / 学术 / 口语 / 职场…），原地替换。

🔒 隐私

用户自带 Key、数据不上云——沉浸式翻译已验证的隐私卖点，runbi 同样能讲。

🖥️ 跨端

浏览器 + 桌面全局覆盖，这是纯扩展类（沉浸式、沙拉查词）做不了的壁垒。

定价锚点参考：海外成熟竞品个人订阅约 $8.74–12/月，大厂中文免费。runbi 若走「免费基础 + 低价 Pro」，可参考 $5–8/月或国内 15–30 元/月。
