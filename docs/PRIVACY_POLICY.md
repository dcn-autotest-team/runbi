# 润笔（Runbi）隐私政策

最后更新：2026-08-29 · 适用版本：桌面客户端 1.0.1+ / Chrome 扩展 1.0.0+

## 一句话版本

**润笔不拥有你的任何数据。** 你选中的文本只发送到你自己配置的大模型服务端点；厂商不设中间服务器，不收集你的文本内容，遥测默认完全关闭。

## 数据流向明细

### 1. 划词 / 剪贴板文本（核心数据）

- 你选中的文本经本地内存处理后，**仅发送至你在设置中自行填写的模型服务端点**（如 DeepSeek、智谱、OpenAI 或你的私有网关）。
- 润笔厂商**不提供、不经过、不存储**任何中转服务。网络直连发生在你的设备与该端点之间。
- 桌面端内置敏感信息拦截：疑似密码、密钥、UUID、手机号、身份证号、银行卡号（校验位验证）的整段文本**不会弹出、不会发送**。
- 扩展端不读取密码输入框（`type=password`）中的任何内容。

### 2. 屏幕截图（仅智能回复功能，默认关闭）

- 仅当你在设置中开启「智能回复视觉感知」并在聊天场景触发时，前台窗口截图会作为视觉输入发送到你配置的模型端点。
- 该功能**默认关闭**；首次触发时会明确询问。关闭设置后截图不发生。
- 截图仅存在于内存中用于当次请求，不落盘、不上传至润笔厂商。

### 3. 本地存储（均在你设备上）

| 数据 | 位置 | 保护 |
| --- | --- | --- |
| API Key | 桌面端 `%APPDATA%\com.runbi.desktop\config.json` | Windows DPAPI 加密，绑定当前用户 |
| 润色历史（默认近 100 条） | 同上 | 明文，可在设置中清除全部历史 |
| 运行日志 `runbi.log` | 同上 | 仅元数据；可在设置中清除 |
| 扩展端配置 | `chrome.storage.local` | 浏览器配置目录 |

卸载说明：桌面端卸载后手动删除 `%APPDATA%\com.runbi.desktop` 目录即可完整清除全部本地数据。

### 4. 遥测与错误上报（默认关闭，永远 opt-in）

- 默认状态下**零网络上报**——没有 DSN 配置时，错误只写入本地日志。
- 你主动开启「错误上报」并填写 DSN 后，仅上传错误堆栈与崩溃信息；**上报内容剥离请求体，不含你划选或润色的任何文本**。
- 「用户反馈」仅在遥测开启时提交你主动输入的文字。

### 5. 自动更新

- 桌面端向公开分发仓库（github.com/dcn-autotest-team/runbi-updates）检查并下载更新包，签名校验（minisign + Authenticode）通过后安装。此过程不携带任何用户数据。

## 我们不做什么

- ❌ 不运营任何收集用户文本的服务器
- ❌ 不默认开启任何网络上报
- ❌ 不分析、不转售、不训练模型于你的任何数据
- ❌ 不在你的设备上植入除划词监听之外的常驻行为

## 联系方式

安全与隐私问题请通过仓库 Issue 或项目维护者联系。本政策随版本更新，重大变更将在 Release 说明中标注。
