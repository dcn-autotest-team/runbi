## TL;DR(五句话)

1. **「Windows 系统级划词 → AI 润色 → 安全贴回」这个组合,国内外都没有直接竞品**——两条调研线独立得出同一结论。
2. 最接近的形态(PopClip/Bob)在 macOS 存活了 15 年并持续收费,证明交互范式成立;但**没人做 Windows**。
3. 唯一的窗口期警报:**Raycast 已发布 Windows 版**;国产侧则要警惕豆包/Kimi 免费侧边栏助手。
4. 定价锚已实采:国内沉浸式翻译 Pro **¥49/月**、海外 Grammarly **$12/月**,Runbi 走 BYOK 免费 + B 端坐席制有明确安全区。
5. 商业化主线确认:C 端免费铺量防占位,B 端(律所/券商/政务)模板包 + 私有化是唯一能避开免费碾压的路。

## 一、竞争格局(三梯队)

| 梯队 | 玩家 | 与 Runbi 关系 |
|---|---|---|
| A 国际写作助手 | Grammarly $12/月、QuillBot、Wordtune、DeepL Write | 扩展端正面竞品;证明订阅模式与三级定价 |
| B 系统级划词工具 ⭐ | PopClip(macOS)、Bob(macOS)、Raycast AI(Mac→⚠️Win)、uTools(全平台) | **形态最接近**;验证付费意愿;Raycast 是最大变数 |
| C 国产插件/输入法 | 沉浸式翻译(2000万用户,Pro ¥49/月)、沙拉查词(开源)、秘塔写作猫、欧路词典(桌面取词)、豆包/Kimi/通义侧边栏、搜狗/讯飞/百度输入法 AI | 免费流量碾压区,避开正面;唯一值得学的是沉浸式翻译 |

## 二、关键发现 Top 5

1. **空窗双确认**:国产侧——输入法 AI 锁输入框、浏览器插件锁网页、欧路锁词典向,无人做"跨应用贴回+剪贴板恢复";海外侧——PopClip/Bob 均止步 macOS。Runbi 桌面端卡位真实。
2. **Raycast Windows 版已出**(实抓官网导航入口):其体验标杆地位 + Windows 落地,估计窗口期 **6-12 个月**,需实测其全局划词/贴回完成度(待办)。
3. **沉浸式翻译是被验证的最佳模板**(实采):划词入口 + 免费引流 + Pro ¥49/月订阅 + "内容零保留"隐私口号,2000 万用户——Runbi 的隐私叙事文案可直接对标。
4. **大厂免费助手威胁大但有软肋**:豆包/Kimi/通义侧边栏免费、模型强,但"通用且交互重";Chrome 商店里大量"豆包/Kimi"插件是**第三方非官方**——官方尚未重注浏览器划词场景。
5. **垂直模板付费意愿已验证**:QuillBot 靠学术、秘塔写作猫靠中文公文/学术细分存活——Runbi 的律所/券商/政务模板包路线成立。

## 三、Runbi 差异化定位(对外文案三件套)

1. **轻**:划词即润、Diff 对比、一键原地贴回(剪贴板隔离+防死锁,专利级细节)
2. **隐私**:BYOK 自选模型,数据不过厂商云,"数据不出域"写进报价单
3. **跨端**:浏览器插件 + Windows 桌面全局热键,一个架构多端复用

对外一句话:**Windows 原生的系统级 AI 划词润色工具**——"Windows 原生/系统级"是唯一的空窗词,别用红海词"AI 润色"。

## 四、定价建议

## 五、风险

1. **Raycast Windows 化**(时间窗 6-12 个月)→ 尽快锁心智 + 商店上架占位
2. **大厂入场**(字节/月之暗面官方重注浏览器划词)→ 靠"系统级+贴回+隐私+B 端"错位防御
3. **技术护城河薄**(Win32 hook 可复制)→ 护城河建在模板资产+客户关系+私有化交付上
