TL;DR

  1. 「中文 × 主动划词触发 × 原地替换 × Windows 桌面端」四要素组合,无直接竞品——注意单要素各有近似者:QuillBot 的 In-Page Editing(划词→浮窗→原地替换)与 Runbi 交互高度重合且已验证 3500 万用户,但不支持中文、无 Windows 桌面端。
  2. 最接近的形态(PopClip / Bob)在 macOS 存活 15 年并持续收费,证明交互范式成立;但没人做 Windows 原生。
  3. 唯一的窗口期警报:Raycast 已发布 Windows 版;国产侧警惕豆包 / Kimi 免费侧边栏助手。
  4. 定价锚已实采:国内沉浸式翻译 Pro ¥49/月(2000 万用户为官方自称)、海外 Grammarly $12/月——Runbi 走 BYOK 免费 + B 端坐席制有明确安全区。
  5. 商业化主线确认:C 端免费铺量防占位,B 端(律所/券商/政务)模板包 + 私有化是唯一避开免费碾压的路。

01竞争格局:三个梯队

梯队 A|国际 AI 写作助手 3 家实采

Grammarly实采

行业标杆 · 扩展 + 桌面 App + Web + Office

  • 定价:Free $0 / Pro $12/月 / Enterprise 联系销售——三级骨架(gamma:实抓 grammarly.com/plans)
  • 规模:4000 万用户 + 5 万机构;触发是「文本有红旗就标注」的被动批改,非「选中即改」的主动划词
  • 基本不支持中文——其商务 empire 建在英文上
  • 模型自家托管、不支持 BYOK;C 端数据过其云
启示:三级定价骨架是被验证的标准打法;但无「系统级跨应用贴回」,且中文盲区正是 Runbi 切入口。

QuillBot二手口径待核最需警惕的交互对标

学术改写之王 · Web + 扩展 + App(官方定价页被 Cloudflare 拦截)

  • 规模:3500 万用户,Chrome 扩展 500 万(商店页面实抓)
  • 定价:免费 + Premium ~$19.95/月(第三方口径,待直连官方核实)
  • 6 个语种,不含中文;词库式改写(Synonym Slider)
  • ⚠️ In-Page Editing(选中文本→浮窗→原地替换)交互模型与 Runbi 高度重合——证明该交互已被大规模验证,也意味着它补中文的速度不可低估
启示:「垂直人群(学术)+ 改写」单一窄场景可撑起一家公司;Runbi 学术英文润色模板可直接对标。

Wordtune实采

逐句行内改写 · 仅英文 · Web + 扩展

  • 规模:1000 万用户;定价 Free / Advanced $6.99+ / Unlimited $9.99+
  • 功能线:Paraphrase / Rewrite / Summarize / AI Writing / Grammar / Humanize AI(AI 味去除)
  • 交互:「多选一建议」而非一键,路径比 Runbi 长
启示:"Humanize AI"是 2024–2026 新长出的需求(AI 内容去味),可加入 Runbi 场景模板。

DeepL Write实采

写作工作台 · 整篇粘贴 · 多语含中文 · Web + 桌面

  • 定价:$8.74–57.49/月,Write Pro $7.49;Web 免费,Pro 捆绑
  • 风格/语气选择、词句备选;独立数据安全页,欧洲企业市场强
启示:「翻译口碑 → 写作助手」路径 + 企业安全叙事拿 B 端;Runbi 私有化话术可参考其数据安全页。

梯队 B|系统级划词工具 ⭐ 形态最接近 Runbi 桌面端

PopClip(macOS)实采

「PopClip appears when you select text in any app」——交互范式与 Runbi 桌面端完全同构

  • 扩展库生态(翻译/复制/搜索/分享),AI 靠扩展 BYOK 接入,无内置 AI
  • 一次买断制,2011 年至今持续更新(2026.8 版)
  • 仅 macOS,无 Windows 版
启示:该交互范式在 macOS 被验证 15 年,付费意愿成立;Windows 上没有等价物——Runbi 桌面端的空窗位。

Bob(macOS)实采

划词翻译 / 截图翻译 / OCR · Mac App Store 分发

  • 30+ 翻译服务 BYOK 聚合(火山/腾讯/阿里/百度/有道/DeepL…)+ 插件系统
  • 主打翻译,无 AI 润色原生体验;无 Windows 版
启示:Bob =「macOS 版 Runbi 的翻译版」,BYOK + 划词 + 服务聚合模式在国内被验证过。

Raycast AI(macOS → Windows)实采最大变数

「AI that works with your OS」· 32+ 模型聚合 · AI Chat + 扩展

  • 订阅制:Pro + AI 加购;体验标杆级产品
  • ⚠️ 官网导航已出现 Windows 入口(raycast.com/windows)——本次调研最重要的单一发现
  • 其 Windows 版全局划词/贴回完成度待实测(空窗期判断的关键变量)
启示:窗口期估计 6–12 个月。Runbi 应尽快锁定「Windows 原生 + 中文场景 + BYOK 隐私」心智。

uTools(全平台)实采

3000+ 插件生态 · 500 万+ 用户 · Alt+Space 全局唤起(与 Runbi 同款热键)

  • 免费 + 会员/企业版;企业内网部署方案;AI 插件创作(Vibe Coding)
启示:双刃——既是生态位威胁,也是渠道(Runbi 可做 uTools 插件借 500 万用户分发);其企业内网部署验证了 B 端私有化需求。

03关键发现 Top 5

  1. 四空位确认(两线独立收敛):中文原生润色(海外四款全不做中文,唯一含中文的 DeepL Write 是整篇工作台)× 主动划词触发(Grammarly 是被动批改)× 原地替换(秘塔是编辑器形态)× Windows 桌面端(QuillBot/Wordtune 连桌面端都没有)——国产侧同样无人做「跨应用贴回 + 剪贴板恢复」。
  2. Raycast Windows 版已出(实抓官网导航入口):体验标杆 + Windows 落地,窗口期估计 6–12 个月;需实测其全局划词/贴回完成度(待办)。
  3. 沉浸式翻译是被验证的最佳模板(实采):划词入口 + 免费引流 + Pro ¥49/月 + 「内容零保留」隐私口号,2000 万用户(官方自称)——隐私叙事文案可直接对标;但「翻译」心智已被它垄断,Runbi 应避开翻译叙事,主打「润色/改写」。
  4. 大厂免费助手威胁大但有软肋:免费、模型强,但「通用且交互重」;商店里大量「豆包/Kimi」插件为第三方非官方——官方尚未重注浏览器划词场景。
  5. 垂直模板付费意愿已验证:QuillBot 靠学术(3500 万用户)、秘塔写作猫靠中文公文/学术细分存活——Runbi 律所/券商/政务模板包路线成立。

04差异化定位

对外主话术(v1.1 采纳):「在中文世界的任何角落,选中即润色,原地替换,隐私不上云。」——三要素:中文原生(海外竞品不做)× 主动划词触发(Grammarly 是被动批改)× 原地替换(编辑器型做不到)。

对外备选(空窗词版):「Windows 原生的系统级 AI 划词润色工具」——「Windows 原生/系统级」是唯一的空窗词,别用红海词「AI 润色」。

轻

划词即润、Diff 对比、一键原地贴回(剪贴板隔离 + 防死锁),一秒换风格,用完即走。

隐私

BYOK 自选模型(DeepSeek/智谱/OpenAI 预设),数据不过厂商云,「数据不出域」写进报价单。

跨端

浏览器插件 + Windows 桌面全局热键,Shared Core 架构一端开发多端复用——纯扩展类做不了。

场景资产

律所/券商/政务等行业模板包:代码可被抄,模板资产 + 客户关系抄不走。

06风险

  1. Raycast Windows 化(时间窗 6–12 个月)→ 尽快锁心智 + 商店上架占位。
  2. 大厂入场(字节/月之暗面官方重注浏览器划词)→ 靠「系统级 + 贴回 + 隐私 + B 端」错位防御。
  3. 技术护城河薄(Win32 hook 可复制)→ 护城河建在模板资产、客户关系、私有化交付上。
